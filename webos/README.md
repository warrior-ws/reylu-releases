# REYLU для LG webOS

Репозиторий Homebrew Channel («кружка»). В настройках выберите «Добавить репозиторий»
и вставьте ссылку:

https://raw.githubusercontent.com/warrior-ws/reylu-releases/main/repo.json

Вернитесь в список приложений и выберите REYLU.

Текущая версия0.1.0 — начальное тестовое приложение: каталог, поиск, фильтры,
информация и управление пультом. **Плеер/воспроизведение пока не реализованы.**
На самом телевизоре LG приложение ещё не проверено. Вход на реальном LG/CORS
также требует проверки; сессия сейчас сохраняется только в памяти.

IPK собран официальным @webos-tools/cli3.2.6 из проверенных исходников. В публикации
оставлены только используемые ресурсы;24 файла приложения совпадают с проверенными
входными файлами. JavaScript и нужные изображения/шрифты сохранены побайтово.
Полные Android/PC-архивы, личные профили и ключи в этот каталог не загружены.
Контрольная сумма IPK находится в SHA256SUMS.txt и в манифесте.

Для обновлений будет использоваться тот же адрес репозитория.
